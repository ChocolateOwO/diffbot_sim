# RRT* วางแผนเส้นทางบนแผนที่ OGM แล้วให้หุ่นยนต์วิ่งตามใน Gazebo

ต่อจากงาน OGM (`ocgm_part2`) และงาน RRT/RRT* (`RTT_and_RTT_star`)

> **ไฟล์ส่งงาน (ไฟล์เดียวรวมทั้งวางแผนและวิ่ง):** `rrt_coppeliasim_660610829.py` + ฉาก `rrt_coppeliasim_660610829.world` (แทน `.ttt`) + `ocgm_660610829.csv` อยู่ใน `rrt_660610829_submission.zip`
> `python rrt_coppeliasim_660610829.py plan` = วางแผน, `python3 rrt_coppeliasim_660610829.py drive` = วิ่ง (launch เรียกให้เอง)
> สองไฟล์แยก (`rrt_star_planner_...`, `follow_path_gazebo_...`) คือฉบับระหว่างพัฒนา ให้ผลเท่ากัน

โปรแกรมทำตามลำดับนี้:

1. โหลดแผนที่ OGM (`ocgm_660610829.csv`)
2. สุ่มตำแหน่งเริ่มต้น (x, y, theta) และตำแหน่งเป้าหมาย (x, y, theta) โดยไม่ให้ทับที่ที่หุ่นยนต์ไปไม่ได้
3. หาเส้นทางด้วย RRT* แบบ offline ได้ลำดับโหนดที่หุ่นควรผ่าน
4. เปิด Gazebo ให้หุ่นเกิดที่ตำแหน่งเริ่มต้นนั้น แล้ววิ่งตามโหนดไปจนถึงเป้าหมายและหมุนให้หันตรงตาม theta ของเป้าหมาย

## วิธีใช้งาน

เปิดเทอร์มินอลใน WSL (ROS 2 + workspace ถูก source จาก `.bashrc` อยู่แล้ว)

```bash
cd "/mnt/e/งาน/271411/rrt_star_part3"
```

**ขั้นที่ 1 — วางแผน (offline)** ได้จุดเริ่ม/เป้าหมายสุ่มใหม่ทุกครั้ง
```bash
~/ocgm_venv/bin/python rrt_star_planner_660610829.py
```
จะเปิดหน้าต่างรูปแผนที่พร้อมเส้นทาง (ไฟล์ `plan.json` ถูกเซฟก่อนเปิดหน้าต่างแล้ว ปิดหน้าต่างได้เลย) ถ้าไม่อยากให้เปิดหน้าต่างใส่ `--no-show`

**ขั้นที่ 2 — ให้หุ่นวิ่งใน Gazebo**
```bash
ros2 launch diffbot_sim rrt_nav.launch.py
```
- Gazebo เปิดขึ้น หุ่นยนต์เกิดที่ตำแหน่งเริ่มต้นของ `plan.json`
- หลังโหลดฉากเสร็จ (~20 วินาที) หุ่นเริ่มวิ่งตามโหนด เลเซอร์ LiDAR แสดงเป็นเส้นสีน้ำเงิน
- วิ่งถึงเป้าหมายและหันตรงตาม theta แล้ว **ทุกหน้าต่างค้างไว้** เทอร์มินอลขึ้นข้อความ `SUCCESS: goal reached` และเซฟ `trajectory.csv` ปิดด้วย Ctrl+C ในเทอร์มินอล (ถ้าอยากให้ Gazebo ปิดเองใส่ `close_when_done:=true`)
- ไม่อยากเปิดหน้าต่าง Gazebo (เร็วขึ้น): `gui:=false`

**หน้าต่างแผนที่สด (เปิดให้เองตอนรันขั้นที่ 2)** — แผนที่ถูก **สร้าง/อัปเดตจากเลเซอร์ระหว่างที่หุ่นเดิน** ซ้ายคือแผนที่ที่ค่อยๆ เปิดออกตามที่หุ่นสแกน (พร้อมเส้นทางน้ำเงิน วงกลมส้ม = หุ่น เส้นแดง = ทางที่เดินแล้ว) ขวาคือแผนที่ OGM ที่ใช้วางแผน ไว้เทียบ จบแล้วเซฟแผนที่ที่อัปเดตเป็น `ocgm_updated_660610829.csv` และ `result.png` ให้เอง
ไม่เอาหน้าต่างนี้: `live_plot:=false` / ดูผลย้อนหลังจากไฟล์: `~/ocgm_venv/bin/python plot_result_660610829.py`

## หลักการทำงานโดยย่อ

**แผนที่ที่ใช้วางแผน.** เซลล์ที่ถือว่าหุ่นไปได้ คือเซลล์ที่ LiDAR เคยเห็นว่าว่างจริง (ความน่าจะเป็น < 0.45) ส่วนเซลล์ตัน และเซลล์ที่ไม่เคยสำรวจ (0.5) ถือเป็นสิ่งกีดขวางหมด จากนั้นขยายสิ่งกีดขวางออกไปเท่ารัศมีหุ่น (0.85 ม. คลุมตัวถัง 1×1 ม. รวมล้อ) แล้วถือหุ่นเป็นจุดเดียว ทำให้ theta ไม่มีผลต่อการชน

**จุดเริ่ม/เป้าหมายสุ่ม.** สุ่มจากเซลล์ว่างหลังขยายสิ่งกีดขวางแล้ว และอยู่ในพื้นที่เดินถึงกันได้เท่านั้น ห่างกันอย่างน้อย 10 ม. (ตั้งได้ด้วย `--min-dist`) theta สุ่มระหว่าง −π ถึง π

**RRT\*.** โครงสร้างเดียวกับ `rrt_660610829.py` (Node, steer, choose_parent, rewire, search_best_goal_node, propagate_cost_to_leaves) เปลี่ยนการตรวจชนจากสี่เหลี่ยมเป็นการดูค่าในกริด และสุ่มจุดจากเซลล์ว่างโดยตรง

**การวิ่ง.** interpolate ระหว่างโหนดทุก 0.1 ม. → เลือกจุด look-ahead 0.6 ม. บนเส้นทาง → ความเร็วเลี้ยวจากมุมที่ต่างกัน → แปลงเป็นความเร็วล้อซ้าย/ขวา (rad/s) → ส่งเข้า `/cmd_vel` ให้ปลั๊กอิน `gazebo_ros_diff_drive` ตั้งความเร็วให้ joint ของทั้ง 4 ล้อ ซึ่งคือสิ่งที่ `sim.setJointTargetVelocity` ทำใน CoppeliaSim

### เทียบกับโจทย์ CoppeliaSim

| CoppeliaSim (zmqRemoteApi) | Gazebo (งานนี้) |
|---|---|
| `RemoteAPIClient()`, `sim.startSimulation()` | Gazebo เปิดด้วย `ros2 launch` ส่วนโปรแกรมต่อผ่าน `rclpy` แทน zmqRemoteApi |
| `sim.getObjectPosition/Orientation` | subscribe `/odom` (ตำแหน่งจริงในโลก) |
| `sim.setJointTargetVelocity(motor, v)` | ความเร็วล้อซ้าย/ขวา → `/cmd_vel` → ปลั๊กอิน diff_drive ตั้งความเร็ว joint ล้อ |
| วางหุ่นที่ตำแหน่งเริ่มต้นแบบสุ่ม | launch ให้หุ่นเกิดที่ตำแหน่งนั้นเลย (`spawn_x/y/yaw`) |

## ข้อควรรู้

1. **OGM ไม่เห็นของเตี้ย.** LiDAR อยู่สูง 0.685 ม. แผนที่ OGM จึงไม่มีโซฟา กรวย เบาะเก้าอี้ ตัวถังรถ แต่ตัวหุ่น (สูงตั้งแต่ 0.02 ม.) ชนของพวกนี้ได้ จึงให้ planner อ่านของเหล่านี้จากไฟล์ `.world` มาเติมเป็นสิ่งกีดขวางเพิ่มด้วย (111 ชิ้น) ค่าเริ่มต้นเปิดอยู่ ถ้าต้องการวางแผนจาก OGM ล้วนๆ ใส่ `--ogm-only` ทดสอบสุ่ม 10 แผน วางแผนจาก OGM ล้วน **6 ใน 10** แผนผ่านใกล้ของที่เซนเซอร์มองไม่เห็นเกินไป (ใกล้สุด 0.27 ม. ตัวหุ่นรัศมี 0.76 ม. จึงชนได้) เมื่อเติมของพวกนั้นเข้าไป **0 ใน 10**
2. **RRT\* เป็นการสุ่ม** รันซ้ำโดยไม่ระบุ seed จะได้เส้นทางคนละเส้น ค่า seed ถูกเก็บใน `plan.json` เสมอ
3. **วางแผนเฉพาะตำแหน่ง (x, y)** หุ่นเกิดที่ theta เริ่มต้น หมุนอยู่กับที่ไปหันหาโหนดแรก วิ่งตามเส้นทาง แล้วหมุนอยู่กับที่ให้ได้ theta ของเป้าหมาย
4. **ต้องรันขั้นที่ 1 ก่อนขั้นที่ 2 ทุกครั้งที่อยากได้จุดใหม่** เพราะ launch อ่านตำแหน่งที่หุ่นเกิดจาก `plan.json`
5. **ปิด Gazebo รอบเก่าให้หมดก่อนรันรอบใหม่** ถ้ามี gzserver ค้างจะ spawn ไม่ได้
6. โปรแกรมวางแผนใช้ Python ใน `~/ocgm_venv` (มี numpy + matplotlib) ส่วนโปรแกรมวิ่งใช้ `python3` ของ ROS ซึ่ง launch เรียกให้เอง
